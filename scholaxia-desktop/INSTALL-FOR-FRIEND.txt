SCHOLAXIA STUDENT — INSTALL ON WINDOWS OR TABLET
=================================================

You received the Scholaxia Student app for Windows PC or Windows tablet.

WHAT YOU NEED
-------------
- Windows 10 or Windows 11
- Internet connection (Wi‑Fi or mobile data)
- About 300 MB free disk space

OPTION A — INSTALLER (recommended)
----------------------------------
1. Close Scholaxia Student if it is open (check the taskbar and Task Manager)
2. Double-click: Scholaxia Student Setup.exe
2. If Windows asks "Do you want to allow this app?", click Yes
3. Follow the install steps → Finish
4. Open Scholaxia Student from Desktop or Start menu

OPTION B — PORTABLE (no install)
--------------------------------
1. Copy Scholaxia-Portable.exe to a folder (e.g. Desktop\Scholaxia)
2. Double-click Scholaxia-Portable.exe

FIRST TIME USE
--------------
1. Open Scholaxia Student
2. Sign up or log in with your student account
3. Use Live Class, CBT, Ask Sia, Community, and Library

TABLET TIPS
-----------
- Works on Windows tablets (Surface, Lenovo, etc.)
- Tap the menu button (☰) if the sidebar is hidden
- Allow camera and microphone when joining live class

TROUBLESHOOTING
---------------
- App won't open: Right-click → Run as administrator once
- Login fails: Check internet; server may be waking up (wait 30 sec, retry)
- Camera/mic: Settings → Privacy → allow Camera and Microphone for Scholaxia

Teachers and admins use separate Scholaxia apps — not included in this student package.

Support: contact the person who sent you this app.
