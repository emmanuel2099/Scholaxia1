SCHOLAXIA STUDENT — INSTALL ON WINDOWS
======================================

You received the Scholaxia Student app for Windows PC or tablet.

IMPORTANT — USE THE INSTALLER FILE
----------------------------------
Install with this file ONLY:

  Scholaxia-Student-Setup-1.0.0.exe

Do NOT use:
- Scholaxia Student.exe inside a "win-unpacked" folder (runs without installing)
- START.bat or BUILD-INSTALLER.bat (for developers only)
- Any file named "Portable" (no install, not for sharing)

WHAT YOU NEED
-------------
- Windows 10 or Windows 11 (64-bit)
- Internet connection
- About 300 MB free disk space

INSTALL STEPS
-------------
1. Close Scholaxia Student if it is already open (taskbar / Task Manager)
2. Double-click: Scholaxia-Student-Setup-1.0.0.exe
3. If Windows SmartScreen appears, click "More info" then "Run anyway"
4. Follow the setup wizard → choose install folder → Finish
5. Open Scholaxia Student from Desktop or Start menu

The installer adds shortcuts and an entry in Settings → Apps so you can uninstall later.

FIRST TIME USE
--------------
1. Open Scholaxia Student from Desktop or Start menu
2. Sign up or log in with your student account
3. Use Live Class, CBT, Skills, Ask Sia, Community, and Library

TROUBLESHOOTING
---------------
- App opened but never installed: you ran the wrong file. Use Scholaxia-Student-Setup-*.exe
- App won't open: Right-click shortcut → Run as administrator once
- Login fails: check internet; wait 30 seconds and retry

Teachers and admins use separate Scholaxia apps — not included in this student package.
