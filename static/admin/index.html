CBT Exams

Practice coupon codes

Generate a code so a student can unlock CBT without Paystack.

Upload CBT practice questions

Papers uploaded here appear under CBT Practice for students. Past papers have their own Past Questions tab.
  1. Pick a .json, .csv, .pdf, or .docx file of questions.
  2. Select the subject and exam board.
  3. Click Upload & create exam(s). For PDF/Word, review the questions, then confirm.
  4. Optional: download the JSON template to see the exact question format.

Review extracted questions

Check every question, fix any mistakes, and set the correct option where it is missing. Untick a question to leave it out. Questions flagged in orange were extracted with low confidence — the exam will be saved unpublished if any flagged question is kept unfixed.
